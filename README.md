#  منصة التوحد لتنمية مهارات التفاعل والتواصل البصري
### Autism Skills & Visual Interaction Platform

منصة تفاعلية وتأهيلية متكاملة تهدف إلى تعزيز مهارات **التواصل البصري**، **التخاطب اللفظي وغير اللفظي (PECS)**، و**التفريغ الحسي والاسترخاء** لدى الأطفال ذوي التوحد، مع توفير **دليل موثق وعملي لولي الأمر** يعتمد على أحدث الدراسات العلمية (مثل توصيات NHS و Autism Speaks).

---

## الميزات الرئيسية للمنصة

-  **تصميم حسي مهدئ (Sensory-Friendly UI & 3D Tactile Layout)**:
  - ألوان ناعمة ومريحة للعين (HSL Soft Colors) تمنع الإجهاد البصري.
  - واجهات زجاجية وتأثيرات ثلاثية الأبعاد (3D Card Tilt Effects).
  - **خالٍ تماماً من الرموز التعبيرية (Emoji-Free UI)** لتجنب أي تشتت أو تفسيرات خاطئة لدى الطفل.

-  **مركز الوسائط المهدئة (Sensory Sound Synthesizer & Media Hub)**:
  - **6 تراكات صوتية طبيعية مخلقة حيوياً (Web Audio API Synthesizer)** بدقة نغمية ودوزنة مهدئة بدون أي ملفات خارجية ثقيلة (تغريد عصافير، خرير مطر، أمواج البحر، همهمة دافئة، أجراس خشبية، وأصوات المزرعة).
  - **10 مقاطع مرئية مخصصة للتخاطب والتفاعل البصري** مع مشغل تفاعلي وأزرار مشاهدة مباشرة موثوقة.

-  **دليل وإرشادات ولي الأمر (10 محاور علمية معتمدة)**:
  - خطوات عمليّة للتعامل مع الرفض والانفعال والتوتر الحسي دون إجبار على التواصل البصري المباشر.
  - نصائح يومية، أنشطة منزلية، وبدائل تشجيعية مجربة لتعزيز التفاعل الطبيعي.

-  **ألعاب تفاعلية ومحاكاة علاجية متدرجة (22+ لعبة بالمستوى الأول)**:
  - **مؤقت تثبيت النظر (Gaze Fixation Timer)**: قياس وزيادة ثواني الانتباه البصري بالتدريج.
  - **محاكي بطاقات PECS**: تواصل بصري ناطق لتعبير الطفل عن احتياجاته (أنا أريد، ماء، لعبة...).
  - **لعبة الأكواب الثلاثية (Cups Shell Eye Game)**: تتبع موقع الكرة بالعين وتعزيز التركيز.
  - **تمييز الأشكال وتتبع الوجوه والأشخاص**: أنشطة متدرجة تناسب قدرات الطفل.

---

## التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 18, Vite 6
- **Styling**: Tailwind CSS 3, Vanilla CSS 3D Transforms & Glassmorphic Effects
- **Animations**: Framer Motion
- **Sound Engine**: Web Audio API (Live Frequency Synthesizer)
- **Icons**: Lucide React Icons
- **Backend Schema**: Prisma ORM (Database Draft)
